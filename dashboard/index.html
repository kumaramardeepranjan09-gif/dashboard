Connect your ESP32

  1. Arduino IDE mein firmware Wi-Fi SSID/password set karke ESP32 par upload karein. GPIO wiring aur required libraries: HARDWARE.md.
  2. ESP32 aur laptop ko same Wi-Fi par rakhein. Serial Monitor (115200 baud) se device IP copy karein.
  3. Browser mein http://DEVICE-IP/api/status open karein. Three motors ka JSON aana chahiye.
  4. Dashboard ko start-dashboard.bat se open karein. Settings mein http://DEVICE-IP enter karein, Demo OFF karein aur Save karein.
  5. Browser local-network permission allow karein. DEVICE ONLINE aur changing readings check karein.
  6. Power/network disconnect karke OFFLINE aur stopped animation verify karein. Reconnect automatically retry hota hai.

RPM sensor firmware mein nahi hai: 3D shaft relay state indicate karta hai, measured speed nahi. Dashboard ko HTTP par run karein; HTTPS page HTTP ESP32 ko block kar sakta hai. VPN, guest Wi-Fi isolation aur firewall bhi connection block kar sakte hain.
